# Contributing

Open an issue describing the problem or proposed behavior before a substantial change. Use a focused branch and include reproduction steps and relevant test results in your pull request.

Create a virtual environment and install `requirements.txt`. Run the Python and JavaScript checks documented in the README. Tests should use fixtures or mocks rather than live controllers.

Preserve command allowlists, argument validation, timeouts, and least-privilege execution. Never commit credentials, inventory files, customer identifiers, operational screenshots, or private endpoints.
